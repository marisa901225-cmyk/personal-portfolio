# Codex Reuse Assets

This repository keeps only a small set of tracked Codex assets:

- `portfolio-ci-fix`: repo-specific CI failure triage and repair flow
- `portfolio-pr-review`: repo-specific PR review comment handling flow
- `portfolio-test-triage`: repo-specific failing test classification flow
- `subagent-prompts.md`: investigation-only prompt templates for `/sub`

Everything else under `.agents/` stays local and ignored on purpose.
